# Google Cloud icons

Official **Google Cloud product icons**, from <https://cloud.google.com/icons> (zip `google-cloud-icons.zip`),
downloaded 2026-11-11 for Cloud Computing session 11 (Cloud Provider Comparison). Google provides them for
architecture diagrams and presentations about Google Cloud. File names are the package's folder names with `_` → `-`
(`virtual_private_cloud` → `vpc-network.svg`).

`google-cloud-wordmark.svg` is the Google Cloud logo (Wikimedia Commons copy of Google's brand asset);
`google-cloud.svg` is the same file with the wordmark paths removed and the viewBox cropped to the four-colour cloud,
nothing redrawn.
