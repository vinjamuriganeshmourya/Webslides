# Azure icons

Official **Azure Public Service Icons V21**, from Microsoft's Azure Architecture Center
(<https://learn.microsoft.com/azure/architecture/icons/>, zip `Azure_Public_Service_Icons_V21.zip`), downloaded
2026-11-11 for Cloud Computing session 11 (Cloud Provider Comparison). Microsoft permits these icons in architecture
diagrams, training and documentation; the package's `Microsoft_Terms_of_Use.pdf` and `Azure_Icons_FAQ.pdf` hold the
terms. Do not redraw them; do not crop or recolour them. `azure.svg` is the package's own "Azure A" mark.
Files renamed to the service name only (e.g. `10021-icon-service-Virtual-Machine.svg` → `virtual-machine.svg`).
