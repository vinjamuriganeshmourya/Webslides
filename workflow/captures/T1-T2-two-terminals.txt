--- notes ---

1. The TR doc previously claimed port 5173, the Vite default. This project sets
   `port: 3000` in vite.config.js, so the doc was patched to 3000. This capture
   is the evidence.

2. `Network: http://10.0.2.15:3000/` is the VM's NAT address. Consider dropping
   this line from the slide: it is real, but it invites the question "what is
   that address", which belongs to Problem 2 and must not be opened here
   (hard rule 4). Keeping only the `Local:` line stays in scope.

3. Django reports `http://127.0.0.1:8000/` because the plain `runserver` form was
   used deliberately, per the capture plan. The student's own history had
   `runserver 0.0.0.0:8000`, which is a bind address and is the wrong thing to
   teach at this point in the course.

4. Accidental bonus capture available: running `.\env\Scripts\activate` and
   `python manage.py runserver` from the project root instead of `backend`
   produced "The term '.\env\Scripts\activate' is not recognized" and
   "can't open file '...\nxttrendz\manage.py': [Errno 2] No such file or
   directory". That is the wrong-folder error hard rule 3 exists for. Worth
   capturing deliberately if a slide or callout wants it.
