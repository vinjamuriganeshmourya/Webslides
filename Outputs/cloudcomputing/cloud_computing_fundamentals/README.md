# Cloud Computing Fundamentals

A 53-slide NxtWave session deck built on the updated base template. The deliverable is
`dist-single/cloud-computing-fundamentals.html`, one self-contained file that opens by
double-click. See `CLAUDE.md` for how it is built and checked.

```bash
npm install
npx vite --port 5270 --strictPort   # the live deck
npm run build:html                  # the deliverable
```
