Slide 18H2

Hook 2: the stall check program

Wrong content

What is wrong. The program on this card is a broken loop on purpose: inside the loop, the if sets ok = True and the else sets ok = False, so ok only keeps the last vote's answer and the program prints True while Harsha is not in CSE-A. A student reads it as a program that makes no sense. In the view the vote walk also plays by itself on a timer and the output box never shows anything until the last press.

What to do. Replace the whole card with the new H2 below. It shows the check by hand written correctly: a flag, a loop that prints who is and is not in CSE-A, and a break as soon as one name is outside. It prints three lines and False, and Sneha is never checked. Then the loop folds into the one line print(set(votes).issubset(cse)), same answer. The poll order changes to Anu, Ravi, Harsha, Sneha. The stall_flag.py program is gone. One press per vote; nothing moves on a timer.

The new program, exactly:

cse = {"Teja", "Ravi", "Kiran", "Anu", "Sneha", "Pooja", "Divya", "Vamsi"}
votes = ["Anu", "Ravi", "Harsha", "Sneha"]
ok = True
for name in votes:
    if name in cse:
        print(name, "is in CSE-A")
    else:
        print(name, "is not in CSE-A")
        ok = False
        break
print(ok)

Its output, exactly:

Anu is in CSE-A
Ravi is in CSE-A
Harsha is not in CSE-A
False

The one line it folds into:

cse = {"Teja", "Ravi", "Kiran", "Anu", "Sneha", "Pooja", "Divya", "Vamsi"}
votes = ["Anu", "Ravi", "Harsha", "Sneha"]
print(set(votes).issubset(cse))
False
