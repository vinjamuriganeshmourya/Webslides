/* =================== the hook: a code with a hash between every character ===
   One moving group, `.hkcomb`. Scaling it by two about the first mark sends
   the marks from cells 1, 2, 3, 4 to cells 1, 3, 5, 7, so the jump getting
   longer IS the argument and the characters never move. The origin is written
   into the transform, because transform-origin on an SVG group is not
   honoured everywhere. */
.hkwrap{display:flex;flex:1;min-height:0;align-items:center;justify-content:center}
.hkfig{display:block;width:100%;height:auto;max-height:100%}
