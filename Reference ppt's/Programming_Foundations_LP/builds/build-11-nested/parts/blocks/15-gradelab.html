Add One More Grade

Type the ladder from the slide, then run a few different marks.

marks = 72
if marks >= 91:
    print("A")
elif marks >= 81:
    print("B")
elif marks >= 71:
    print("C")
elif marks >= 61:
    print("D")
else:
    print("F")

95, 85, 72, 65, 40 should give A, B, C, D, F.
