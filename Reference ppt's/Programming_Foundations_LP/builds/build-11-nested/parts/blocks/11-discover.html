Conditional Statements

Your Turn

I have a student's marks out of 100 and I need to print their grade.

91 to 100   ->   A
 81 to 90   ->   B
 71 to 80   ->   C
 61 to 70   ->   D

How would you write that with what you know so far? Three minutes, on your own screen.

You already have everything you need. There is no new keyword yet.

Four ways to write it with today's keywords, two at a time. Here are the first two.

1 · One if per grade

if marks >= 91:
    print("A")
if marks >= 81:
    print("B")
if marks >= 71:
    print("C")
if marks >= 61:
    print("D")

Wrong. 95 prints A, B, C and D — every question is still asked after a match.

2 · Both ends of every band

if marks >= 91:
    print("A")
if marks >= 81 and marks <= 90:
    print("B")
if marks >= 71 and marks <= 80:
    print("C")
if marks >= 61 and marks <= 70:
    print("D")

Correct — but every boundary is written twice, and all four questions are asked every time.

And the other two. Three of the four are correct. Every one costs you something.

3 · An if inside an if inside an if

if marks >= 91:
    print("A")
else:
    if marks >= 81:
        print("B")
    else:
        if marks >= 71:
            print("C")
        else:
            if marks >= 61:
                print("D")

Correct, and asks nothing extra — but four levels deep. One more grade, one more level.

4 · Keep the answer in a name

grade = "D"
if marks >= 71:
    grade = "C"
if marks >= 81:
    grade = "B"
if marks >= 91:
    grade = "A"
print(grade)

Correct and flat — but the answer is overwritten up to three times, and 20 comes out as D.

So, what should we do now?

All these approaches have downsides.
