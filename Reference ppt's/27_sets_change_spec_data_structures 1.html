27 Sets: add what a data structure is

File to change: python-session-27-sets.html. Everything not listed here stays exactly as it is.

An instructor asked that every data structure session first says what a data structure is, and what today's one is, before any code. This adds two standard cards before the set's code. The same cards are going into Lists, Tuples and Dictionaries, so the grid card is one component that gains a column each session.

What to do

  1. Add 2 new cards: DS2 (Python's four data structures), DS3 (What a set is). Where they go is in the card order below.
  2. Change C1: only the lines shown below.
  3. Update the minutes on the beats listed below, if the view shows them.
  4. Give each new card its id (DS2, DS3) the same way the view names its other cards, so it can be checked against the spec.

New card

Purpose. Python has four built-in data structures. Today's is the set; the room has already met the list and the tuple.

Exact words on the card

Four data structures in Python

A data structure holds many values under one name.

Four tiles side by side, one per data structure.

PressOn screenInstructorRoom
1The line A data structure holds many values under one name. over four face-down tiles.We have met this word before. What is a data structure?Say it in your own words.
2Tile 1 turns over: the picture A playlist, the name list, and the line Songs in order. A song can come twice. It gets a small tick: already learnt.We know this one. Ask the room for its line before you press.Say the line.

5Tile 4 turns over: the picture Contacts, the name dictionary, and the line Look up a name, get the number. It stays dim, marked Later.Name it only. It comes later.

Must.

  • All four tiles are on the card from press 1, face down, so nothing jumps.
  • Only the names and the everyday pictures. No code and no brackets for a structure not yet taught.
  • The set tile ends lit; earlier tiles keep their tick.
  • Draw it in the phone world: a playlist is a list, a date of birth is a tuple, Seen by is a set, Contacts is a dictionary. Do not take the picture further than this: the apps do far more than keep values; only the shape of the data carries over

listtupleset

Same item twice?YesYesNo

Must.

  • The whole grid, row labels and empty cells, is on the card from press 1. One cell of today's column fills per press.
  • Earlier columns never change. The room reads today's cell against them.
  • Each filled cell keeps its proof beside it: the code and its exact output from data.proofs.

Must not.

  • Fill a cell before the room has voted on it.
